# Лабораторная работа №3. Обучение с учителем: Регрессия, Ансамбли и Нейронные сети (Вариант 12)

Проект выполняет сравнительный анализ методов машинного обучения и глубоких нейронных сетей (PyTorch) в задаче одношагового ($t \to t+1$) и многошагового ($t \to \{t+1, \dots, t+7\}$) прогнозирования временного ряда для **Варианта 12** по дисциплине «Машинное обучение» (ДГТУ).

## Установка зависимостей и запуск

1. Перейдите в каталог проекта:
   ```bash
   cd D:/projects/python/ML_lab/lab3_gm
   ```
2. Убедитесь, что активировано виртуальное окружение с установленными библиотеками:
   ```bash
   pip install numpy pandas scipy scikit-learn torch matplotlib openpyxl
   ```
3. Запустите основной скрипт:
   ```bash
   python main.py
   ```
